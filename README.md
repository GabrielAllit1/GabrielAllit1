## Design principles

- Treat model output, action completion, and telemetry as **evidence**, not automatic authority.
- Make authority boundaries explicit before AI is allowed to change durable state or physical systems.
- Prefer **local-first and deterministic fallback** paths where they improve privacy, reliability, or inspectability.
- Separate unit/simulation success from hardware, field, and external-validation claims.
- Preserve provenance with receipts, manifests, hashes, CI evidence, and reproducible artifacts.
- Build around reusable system boundaries rather than one-off demos or thin model wrappers.
