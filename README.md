## Shared architecture

Across these systems, the recurring engineering pattern is:

```text
observe
  -> estimate
  -> preserve evidence
  -> reason / propose
  -> authorize
  -> execute
  -> verify
  -> record provenance
  -> learn only through governed promotion
```

The objective is not simply more model output. The objective is inspectable systems where evidence, authority, execution, verification, and learning remain distinct enough to test, audit, replay, and constrain.
