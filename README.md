## Engineering principles

- Treat model output, estimator output, action completion, and telemetry as **evidence**, not automatic authority.
- Preserve source identity, time, provenance, uncertainty, dependencies, and health through the decision path.
- Make authority boundaries explicit before AI or autonomy is allowed to change durable state or physical systems.
- Degrade deterministically when evidence, integrity, freshness, or dependencies no longer justify higher authority.
- Prefer **local-first and deterministic fallback** paths where they improve privacy, reliability, or inspectability.
- Separate unit/simulation/SIL success from HIL, field, external-validation, certification, and production claims.
- Preserve provenance with receipts, manifests, hashes, replay, CI evidence, and reproducible artifacts.
- Build around replaceable interfaces and reusable system boundaries rather than one-off demos or thin model wrappers.
