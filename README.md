## Engineering principles

Across projects I repeatedly use the same architectural ideas:

```text
observe
  -> estimate
  -> build evidence
  -> reason / propose
  -> authorize
  -> execute
  -> verify
  -> record provenance
  -> learn only through governed promotion
```

The goal is not merely to make model output more fluent. It is to build systems in which state, evidence, authority, execution, verification, and learning remain inspectable and separable.
